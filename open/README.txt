离职开店 · 深夜小馆

打开方式
双击 index.html 即可玩，无需安装依赖、无需服务器。
请把 index.html、style.css、app.js 放在同一个文件夹。

部署到 GitHub Pages
把以上三个文件上传到你的网站仓库的一个子目录，例如 quit-and-open/。
部署完成后访问 https://poppinxh.github.io/quit-and-open/。
本次未自动上传或修改你的 GitHub 仓库。

玩法
本金十万元，三万二用于装修押金，余额六万八。
调整价格、备货、人手，开门后处理一个事件，再查看账单。
营业三十天，或现金耗尽、精力耗尽时结束。
经营数据自动存储在当前浏览器中，不跨设备同步。
刷新可以恢复经营状态；重新开店会覆盖当前存档。

这是规则驱动的可玩原型，不包含实时 AI、自由生成店铺或多人联机。
天气、顾客话语和事件为内置内容。经营销量含随机波动。

测试
若安装 Node.js，可运行 node test.cjs 验证三十天流程与账目、存档恢复。

# 造字局 · 汉字炼金术 ZI FORGE

把两个字拆开，炼一个世上没有的字。

纯前端，无依赖，不联网。双击 `index.html` 就能玩。

---

## 这是什么

中文里有些字本来就是拼出来的：日 + 月 = 明，木 + 木 = 林，人 + 木 = 休。
这个页面把这条规则开放出去：**你出偏旁，炉子出字。**

两个偏旁丢进炉里，页面当场造出一个**不存在于任何字典里的汉字**，并给它配全一套辞书条目：

| 项 | 说明 |
| --- | --- |
| 字形 | 按左右 / 上下结构真实排版，带米字格 |
| 读音 | 合法拼音音节 + 声调符号，同字同音 |
| 字义 | **由五行生克推导**，不是从词库抽样 |
| 造字法 | 叠体 / 会意·同部 / 同气 / 相生 / 受生 / 相克 / 受克 |
| 九星 | 入中哪一星，属什么五行，吉或凶 |
| 命盘 | 一张属于这个字的九宫飞星盘（顺飞） |
| 元运 | 依三元九运算当运 / 退运 / 生气 |
| 坐向 | 二十四山里的一座坐山 |
| 字品 | 凡品 → 天授（★1–5） |
| 另附 | 结构、笔画、引申句、可造的词 |

## 字义是推导出来的

这是本项目最关键的一处设计：**先定关系，再由关系决定字义。**

每个偏旁归属一个「意场」，每个意场带五行。于是任取两个偏旁，它们的关系是唯一确定的：

- 水 + 木 → 水生木 → **相生**：「暗流养木屑。」
- 水 + 火 → 水克火 → **相克**：「暗流一冲，火苗就没了。」
- 木 + 水 → 木受水生 → **受生**：「年轮靠潮水活着。」
- 日 + 月 → 同属光意 → **同部**：「光斑与灯影，同一件事的两面。」
- 木 + 木 → **叠体**：「年轮叠年轮，其意加倍。」

七种关系各有独立的句式、词池与用例写法，所以形似的组合读起来也不同。
同一个配方永远炼出同一个字（结果由「结构 + 部件」的哈希决定，不随机跳动）。

## 玄空风水：字也有命盘

按玄空飞星的做法，给每个炼出来的字起一张盘：

- **入中星**：由「谁成事」定星的五行（相生取被养者、相克取胜者），再在九星里取数。
- **飞星盘**：入中星落中宫，依 中→乾→兑→艮→离→坎→坤→震→巽 顺飞九宫，九数循环。
- **洛书九宫**：四巽、九离、二坤、三震、五中、七兑、八艮、一坎、六乾。
- **三元九运**：每运二十年，一运起于 1864 年；2024–2043 走九运。星＝当运者记「当运」，字品加一；五黄入中减一。
- **二十四山**：由哈希定坐山，反向为向，写在盘下。

**九宫字局盘**是收集目标：炼出的字入中哪一星，就点亮洛书里的哪一宫，九星齐全即算圆满。
点击宫位可以看该星的名字、五行、吉凶与所主。

## 缺字：给说不出口的事造一个字

「这个字想叫什么」是可选的一栏。写下一件还没有名字的事——想辞职又不敢的那阵子、明明没事却一阵心慌、离别时没说完的半句——再造字给它。

一旦填了，条目和导出的卡片上就会出现一行「**为「……」立一字**」。
字从这里开始有了存在的理由，也才可能被转发。

## 解字 · 问一日

给一个日子和一个字，看它们之间有什么。字可以是任意汉字，也可以是炉里刚炼的。

| 取数 | 怎么算 |
| --- | --- |
| 日柱干支 | 儒略日数推六十甲子（锚点校验：2000-01-01 戊午、1949-10-01 甲子） |
| 年柱干支 | 公历年干支（未按立春细分，年界日附近有一天误差） |
| 月柱干支 | 由最近「节」定月建，再以五虎遁（甲己之年丙作首）推月干 |
| 纳音 | 六十甲子纳音表（丙午＝天河水，癸未＝杨柳木） |
| 节气 | 二十四节气平气日，给出所处节气与距下一节气天数 |
| 消息卦 | 月建对应的十二辟卦（戌月值剥，子月值复） |
| 地支关系 | 日支与月建之间的六冲、六合、六害、三合 |
| 卦 | 以年月日干支序数加字之笔画取数，定上卦、下卦与动爻，查六十四卦 |
| 相会 | 日干五行 × 此字五行 → 生、受生、克、受克、同气 |

最后合成一句断语：`「卦名」某爻动，＋ 生克判语`。

起卦用的是「以数起卦」的路子（卦以数起），但取的是干支数而非农历月日，
所以它是一套**自洽可复算**的规则，不是对某一种古法的复刻。

## 其他

- **我的字典**：炼出的字可收进本地字典，最多 120 条，存 `localStorage`，不跨设备同步。
- **导出卡片**：一键生成 1000×1400 PNG——宣纸底、双线朱砂框、米字格、拼音、规格、九宫飞星盘、释义、朱砂印。
- **主题 / 音效**：右上角切换深浅色与炼字音效（Web Audio 合成，无音频文件）。
- **随手一炼**：随机两个偏旁，或按 `Ctrl/Cmd + Enter`。
- **未成字**：改了偏旁但没重炼时，旧字卡会变灰并盖上斜章，避免误存。
- **可访问性**：键盘全程可操作，结果区 `aria-live` 播报，尊重 `prefers-reduced-motion`，对比度按 WCAG AA 选取。

## 边界

不接大模型：字义来自「五行关系 × 内置意场词池」的组合，不是 AI 现写。
好处是离线、确定、瞬间出结果，且同一个字永远一致；代价是语料有限，玩久了会撞见熟悉的句式。
玄空部分是按真实规则实现的推演（洛书、顺飞、元运、二十四山），但把「字的命盘」当作一种文化化的叙事，不作任何吉凶断言。

# 字相 · 一字之相

问一个字，看它今日之相。

纯前端，无依赖，不联网。双击 `index.html` 就能用。

---

## 这是什么

一个字有它的形、它的意、它的五行与九星；一日有它的干支、节气与卦。
两下相遇，出一页**字牒**。

写一个字，可选给一个日期，得到六节：

| 节 | 内容 |
| --- | --- |
| 壹 · 形 | 拆作哪些部件、部件名、笔画、六书归属（独体 / 叠体 / 同部 / 会意） |
| 貳 · 意 | 部件之间是生还是克，由此推出一句字义、一句引申、一句题句 |
| 叁 · 星 | 入中哪一星（九星名、别名、五行、吉凶、所主）、顺飞九宫盘、当运与否、坐山朝向 |
| 肆 · 日 | 年月日三柱干支、当前节气与距下一节气天数、年纳音与日纳音、月建与当值消息卦 |
| 伍 · 会 | 日干五行 × 此字五行 → 生/受生/克/受克/同气；日支与月建之间的冲合害、三合局 |
| 陸 · 卦 | 以干支序数加字之笔画取数，定上卦、下卦与动爻，查六十四卦 |

末了一句断语：`「卦名」某爻动，＋ 生克判语`。

**两种用法**

- **带日期**：字与这一日相遇，六节齐全。
- **只解字**：点「清空日期」，就去掉 肆 / 伍 / 陸，只留形、意、星，断语转为星与运。

## 取数规则

全部可复算，同一个字、同一日，永远同一页。

| 项 | 怎么算 |
| --- | --- |
| 拆字 | 内置拆字表；表外的字按整字取象，并在「形」里注明 |
| 五行 | 由部件所属意场推断，取部件中出现最多者 |
| 日柱 | 儒略日数推六十甲子（锚点校验：2000-01-01 戊午、1949-10-01 甲子） |
| 年柱 | 公历年干支 |
| 月柱 | 由最近一个「节」定月建，再以五虎遁推月干 |
| 纳音 | 六十甲子纳音表 |
| 节气 | 二十四节气平气近似日 |
| 消息卦 | 月建对应的十二辟卦（戌月剥、子月复……） |
| 九星 | 由字的五行在其所属九星中定，再依 中→乾→兑→艮→离→坎→坤→震→巽 顺飞 |
| 卦 | 干支序数与笔画取数定上下卦与动爻 |

## 其他

- **字牒册**：看过的字可存下（最多 60 条，存 `localStorage`），点一下就能重新翻出来。
- **导出字牒**：一键生成 1000×1400 PNG——宣纸底、双线朱砂框、米字格、拆字与规格、干支与卦、断语、朱砂印。
- **主题 / 音效**：右上角切换深浅色与问世音效（Web Audio 合成，无音频文件）。
- **可访问性**：键盘可全程操作，结果区 `aria-live` 播报，尊重 `prefers-reduced-motion`，对比度按 WCAG AA 选取。

## 边界（请先看一眼）

- **笔画是构件累加**，与标准笔画可能差一两画，页面上也标了这句。
- **拆字表有限**。表内的字拆得准，表外的字按整字取象，结果会粗。
- **年柱不按立春细分**，年界那几天可能差一年；月建用平节气，节气日边界可能差一天。
- **起卦取干支数**，属「卦以数起」的路子，但不是对某一古法的复刻。
- 九星、卦、纳音这些按真实规则实现，用来给字一个叙事骨架；**不作吉凶断言，也别当预测工具**。
